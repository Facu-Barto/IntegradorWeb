Nombre del Proyecto: Sonido Montañez Medina - Trabajo Final Integrador (TFI)

Descripción:
Sitio web multipágina desarrollado para el Trabajo Final Integrador de la Materia Programación Web 1 En la Tecnicatura Universitaria en Desarrollo de Software de la ULP. 
El proyecto presenta un servicio profesional de sonido e iluminación, implementando una estructura con HTML, CSS y JavaScript.
Tiene un diseño adaptable para distintos Dispositivos y una paleta de colores especifica. 
Cuenta con un carrusel de imágenes interactivo en JavaScript y un sistema completo de validación de formularios con expresiones regulares, manejo de errores en el DOM y envío de datos.

Instrucciones básicas de uso:
1. Clonar el repositorio en su PC o abrir el ultimo despliegue de GitHub Pages.
2. Abrir el archivo 'index.html' en cualquier navegador web.
3. Utilizar el menú de navegación superior para navegar entre la página principal, los servicios de DJ, los servicios de sonido y la sección de contacto.
4. En la página de 'Contacto', completar los campos obligatorios respetando las validaciones en tiempo real (formato de correo, teléfono y fechas válidas) para probar la manipulación del DOM y el envío de consultas.
